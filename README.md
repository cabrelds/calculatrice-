# \# Calculatrice Scientifique — SCILAB fx-9860 PRO

# 

# Projet réalisé en équipe de 6 étudiants dans le cadre d'un cours de développement web.

# 

# \## Description

# Une calculatrice scientifique complète développée en HTML, CSS et JavaScript pur.

# 

# \## Fonctionnalités

# \- Opérations arithmétiques de base (+, −, ×, ÷)

# \- Fonctions trigonométriques (sin, cos, tan et inverses)

# \- Puissances et racines (x², x³, √, ∛, xʸ)

# \- Logarithmes (log, ln, log₂)

# \- Constantes mathématiques (π, e)

# \- Mémoire (MC, MR, M+, M−)

# \- Support clavier physique

# \- Mode DEG / RAD

# \- Fonctions hyperboliques (sinh, cosh, tanh)

# 

# \## Installation

# 1\. Cloner le dépôt

# 2\. Ouvrir `index.html` dans un navigateur
